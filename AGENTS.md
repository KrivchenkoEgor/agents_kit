## ⛔ КРИТИЧЕСКИЕ ЗАПРЕТЫ (читать до начала работы)

### 1. 🚫 Картинки в чате запрещены
Модель DeepSeek в этом окружении **не видит изображения**. Отправленный скриншот/PNG/JPG мгновенно и необратимо уронит сессию: весь прогресс, чат и контекст сгорят.

Правила для агента:
- **При первом сообщении каждой сессии** предупреждай пользователя: *«Не присылай картинки — я их не вижу, и сессия упадёт. Всё присылай текстом или файлами.»*
- Никогда не отправляй изображения модели и не проси «что на картинке»
- Графики, которые я строю в `plots/` — только для пользователя; корректность проверяю **программно по данным**, а не смотря на PNG
- Если пользователю нужно передать визуальную информацию, предлагай альтернативы:
  | Вместо | Сделай |
  |--------|--------|
  | скриншот ошибки | скопируй текст ошибки |
  | скриншот таблицы | сам файл (.xlsx/.csv) |
  | скриншот графика | опиши словами, что хочешь увидеть |
  | фото задания | перепиши текст |

### 2. 🚫 Исходные данные неприкосновенны
Файлы в `data/` никогда не изменяются. Все преобразования — только в новые файлы в `output/`.

### 3. 🚫 Никогда не останавливаться
«Не могу» — не ответ. Состояния «не работаю» не существует.

## 🗂 Данные: любой файл, всё в работе
- Работай с любым файлом пользователя; не фиксируйся на конкретных данных
- Файлы читаются **целиком**: все листы, все строки, все столбцы. Сэмплирование «для скорости» — только с разрешения
- Никакого молчаливого удаления строк/столбцов — очистка только через «план + ОК»
- После любой операции — сверка строк «было/стало» и отчёт пользователю
- Значения с ведущими нулями (коды типа `00014`) читаются как текст (`dtype=str`)
- Огромные файлы, не влезающие в память — обрабатываются кусками (`chunksize`), но всё равно целиком
- Несколько файлов: работа раздельно; при первом упоминании нового файла один раз спроси: «отдельно, объединить или сравнить?». Молчаливого склеивания не делать

## 🔌 Context7 MCP — обязательно

Context7 даёт свежую документацию библиотек и защищает от ошибок из-за устаревших методов (знания модели могут быть устаревшими).

**Первый запуск:**
1. Проверь: вызови tool `resolve-library-id` с параметром `pandas`
2. Если нет — установи:
   a. Проверь `npx`: `npx --version`
   b. Если Node.js нет — поставь сам:
      - Windows: `winget install OpenJS.NodeJS.LTS`
      - macOS: `brew install node`
      - Linux: `sudo apt install nodejs npm`
   c. Зарегистрируй MCP-сервер в настройках IDE на уровне **USER**:
      ```json
      { "mcpServers": { "context7": { "command": "npx", "args": ["-y", "@upstash/context7-mcp"] } } }
      ```
   d. Запасной вариант (если локальный не работает): `{ "type": "http", "url": "https://mcp.context7.com/mcp" }`
3. Результат подключения — в `progress.md`, грабли — в `LESSONS.md`

**Использование:** всегда перед написанием кода с любой библиотекой (`resolve-library-id` → `query-docs`). Базовый синтаксис Python — не нужно.
**Если Context7 недоступен** — всё равно выполняй задачу. Состояния «не работаю» не существует.

## 🧠 Память и самообучение

| Файл | Роль | Как меняется |
|------|------|--------------|
| `AGENTS.md` | Конституция | Редко, с одобрения |
| `LESSONS.md` | Журнал приёмов и граблей | Растёт после успешных задач |
| `progress.md` | Дневник проекта | По выполненным задачам |
| `checkpoint.md` | GPS состояния | Перед длинными операциями |

**`checkpoint.md`:**
- При старте сессии — читается первым (вместе с `progress.md`) и восстанавливает контекст
- Обновляется перед любой длинной операцией
- После завершения задачи — чистится секция «что делаю сейчас»

**`LESSONS.md`:**
- Записываются уроки только за **новые** наблюдения: особенность данных, рабочий приём, грабли. Рутина не логируется
- Выращивание: повторяющиеся и доказанные уроки — предлагай пользователю закрепить в `AGENTS.md`; добавляй только с одобрения
